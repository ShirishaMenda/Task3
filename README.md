# Task 3: EC2 Provisioning & Strapi Setup

## Overview
This project demonstrates provisioning an EC2 instance using Terraform modules, generating a `.pem` key, and deploying a Strapi application on it.
---

## Steps Completed

1. **Terraform Setup**
   - Created EC2 instance using a module.
   - Generated `.pem` key managed by Terraform.
   - Applied Terraform to provision infrastructure.

2. **Strapi Setup**
   - Cloned Strapi repository.
   - Installed dependencies (`npm install`).
   - Created a new Strapi project.
   - Ran Strapi locally (`npm run develop`).
   - Accessed Admin Panel and created a sample content type.

3. **GitHub**
   - Pushed Terraform and Strapi setup to GitHub
